Reserved keywords are labels that cannot be used as variable names.

Today the reserved keywords are:
- `all`
- `cd`
- `clear`
- `cwd`
- `dir`
- `exec`
- `help`
- `exit`
- `quit`

`append` and `pop` are not reserved keywords.

They are only recognized as method names when used after an object label, for example:
- `a.append("x")`
- `a.pop(3)`
