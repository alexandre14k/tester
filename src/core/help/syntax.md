The repl currently supports simple line-based statements.

Assignment:
- `a="hello"`
- `b="world"`

Lookup:
- `a`

String concatenation:
- `c=a+" "+b`

Method calls on string variables:
- `a.append(" ")`
- `a.append(b)`
- `a.pop(3)`

Help commands:
- `help()`
- `help("syntax")`

Command calls:
- `all()`
- `clear()`
- `cwd()`
- `cd("path")`
- `dir("path")`
- `exec("line")`

Comments start with `#` and continue to the end of the line.
